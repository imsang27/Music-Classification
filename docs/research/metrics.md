# 평가 지표 읽는 법

프로젝트의 과거 평가에서 사용한 지표를 설명합니다. 값이 높아도 평가한 자료·참조·모델·출력 범위를 넘어 현재 태깅 전체의 정확도로 확대하지 않습니다. 실제 수치는 [공개 실험 기록](archive-index.md), 현재 구성은 [분석·평가 안내](README.md)를 확인하세요.

| 지표 | 무엇을 세는가 | 주의할 점 |
|---|---|---|
| hit@1 | 첫 후보가 해당 곡의 관측 참조 목록에 들어간 곡의 비율 | 누락된 공개 태그는 청취상 오답을 확정하지 못함 |
| hit@3 | 상위 3후보 중 적어도 하나가 관측 참조 목록에 들어간 곡의 비율 | 후보 3개가 모두 맞았다는 뜻이 아니며 hit@1과 같은 난이도도 아님 |
| 표본 내 일치율 | 고정된 표본에서 합의 참조와 일치한 비율 | 다른 음악·가수·장르로 일반화한 정확도와 다름 |
| 재현율 | 참조 양성 중 양성으로 찾아낸 비율 | 오탐이 많아도 높을 수 있어 단독 해석하지 않음 |
| 균형 정확도 | 이진 평가에서 양성 재현율과 음성 재현율의 평균 | 유효한 양성·음성 참조가 모두 필요함. 모름·미주석을 음성으로 채우지 않음 |
| F1 | 정밀도와 재현율의 조화평균 | 경계값과 양성 비율·참조 누락에 영향을 받음 |
| ROC-AUC | 양성에 음성보다 높은 점수를 주는 순위 성능 | 특정 경계에서의 오탐률이나 실제 정답 확률을 뜻하지 않음 |
| AP / macro AP | 라벨별 average precision 및 유효 라벨의 단순 평균 | 사다리꼴 PR-AUC와 다름. 보고서마다 포함 라벨 수와 미등록 태그 처리 확인 필요 |
| Spearman ρ | 사람의 강도 순위와 모델 점수 순위의 관련성 | −1~1의 상관계수이며 정확도 백분율이 아님. 강도의 절댓값이나 감정 유무를 맞췄다는 뜻도 아님 |
| 95% 재표집 구간 | 정해진 단위와 방식으로 다시 뽑았을 때 나타난 추정치 범위 | 작은 표본·선택 편향·공유 평가자·사전학습 중복을 자동으로 해결하지 않음 |
| 자동 테스트 통과 수 | 구현이 정한 동작·오류 처리 조건을 만족한 검사 수 | 음악 태그가 사람에게 어울리는 비율과 별개 |

예를 들어 ρ=0.767은 정확도 76.7%가 아닙니다. hit@3=36/37은 그 37곡에서 상위 3개 중 하나가 참조에 포함됐다는 뜻입니다. 모델 교체 후 hit@1이 늘어도 특정 장르의 성능이 떨어질 수 있으므로 합계와 항목별 손실을 함께 봅니다.

MuQ의 원시 유사도는 같은 구성 안에서 후보를 순위화하는 값입니다. 음수도 가능하며, 임의로 0~100으로 바꿔 신뢰도나 정답 확률로 표시하지 않습니다. 서로 다른 모델·문구 집합의 원시 점수도 직접 더하거나 비교하지 않습니다.

보고서를 읽을 때는 다음 순서로 범위를 확인합니다.

1. 어떤 모델·설명 버전·라벨 공간을 평가했는지 확인합니다.
2. 전체 곡인지 발췌인지, 몇 곡·몇 아티스트·몇 원곡 그룹인지 확인합니다.
3. 참조가 업로더 태그인지 사람 합의인지 선택한 사람들의 강도 평균인지 확인합니다.
4. 학습·개발·선택에 사용한 자료인지 별도로 남긴 시험 자료인지 확인합니다.
5. 개선과 손실, 불확실성, 미지원 항목과 미주석 항목을 함께 확인합니다.
