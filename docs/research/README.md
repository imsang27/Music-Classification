# 분석·평가 기록과 현재 태깅 구성

2026-10-29 · 공개 코드 0.6.0 기준

현재 실행법은 [로컬 태깅 안내](../desktop-tagging.md), 이전 비교·학습·오류 분석은 [공개 실험 기록 16개](archive-index.md), 수치의 의미는 [지표 읽는 법](metrics.md)에 정리했습니다. 이 문서는 기존 결과를 정리한 것이며 새 평가나 학습을 수행한 결과가 아닙니다.

## 현재 사용하는 구성

`익숙한_표현_태깅_실행.cmd` 또는 `tag_audio.py --profile familiar`는 **OpenMuQ/MuQ-MuLan-large**로 음원과 고정 영어 설명의 관련도를 비교합니다. 현재 태깅 경로의 모델 가중치는 추가 학습하지 않았습니다. 가사 의미·곡 제목·아티스트·앨범을 판단 입력으로 사용하지 않습니다.

| 항목 | 현재 구성 |
|---|---|
| 장르 | 25개 설명 중 후보 선택 |
| 감정 | 신남·슬픔·분노·불안·설렘·그리움·외로움·희망·사랑 |
| 분위기 | 잔잔·몽환·따뜻·시원·웅장·발랄·편안·어둠·낭만·Energetic·Chill |
| 표시 | 감정·분위기 각각 상위 3후보, 대표값 별도 표시 |
| 결과 의미 | 3개의 확정 태그 또는 보정된 정답 확률이 아닌 추천 순위 |

실제 설명은 [familiar v2 리소스](../../music_classification/resources/familiar_candidate_prompts_v2.json), 표시 이름 정책은 [별도 리소스](../../music_classification/resources/familiar_display_names_v1.json)에 있습니다. 25+9+11은 이 프로그램에서 정한 설명 수입니다. 모델의 고정 학습 클래스 수나 독립적으로 검증한 항목 수를 뜻하지 않습니다. 일본 노래·우타이테·커버도 같은 오디오 경로로 분석하며, J-pop이라는 출처 범주만으로 세부 음악 스타일을 확정하지 않습니다.

이전 69개 설명, 44개 계층 후보, 감정 8문구, Music2Emo의 원래 56개 출력, GTZAN 계열 10장르는 서로 다른 구성입니다. 과거 보고서의 기본값·라벨·API 버전·다음 단계는 작성 당시 기록으로 읽어야 합니다.

| 실험 | 자료·참조 | 관측 결과 | 현재 구성에 적용할 수 없는 해석 |
|---|---|---|---|
| [MuQ 감정 강도](archive/MuQ_감정강도_비교결과.md) | Emotify+ 중 항목별 강도 참조가 있는 20~29곡 | happy ρ=0.369, joyful 0.437, sad 0.119, anxious 0.167 | 감정 유무 정확도나 현재 9개 감정 전체 성능 아님 |

표본·라벨·참조·모델이 다르므로 이 수치들을 평균해 전체 정확도를 만들 수 없습니다. 좋지 않은 결과와 채택하지 않은 실험도 기록에 포함했습니다. 과거 작은 장르 판별기를 실제 학습한 이력과, 현재 familiar 경로에서 추가 학습 없이 실행한다는 사실은 구분해야 합니다.

## 현재 확인된 범위와 한계

파일·링크 입력, 모델 호출, 상위 후보 표시, 결과 저장, 임시 오디오 정리는 실행을 확인한 기능입니다. 공개 코드 반영 시 자동 검사 36개 중 34개가 통과했고 개인 자료를 요구하는 2개 감사 검사는 제외됐습니다. 이 숫자는 분류 정확도가 아닙니다.

현재 familiar v2 전체의 일반화된 장르·감정·분위기 정확도는 산출하지 않았습니다. 익숙한 곡에 대한 개인 사용 적합성 확인은 별도로 있었지만, 그 피드백을 공개 벤치마크나 모든 청자의 정답으로 바꾸지 않습니다. 신남·발랄처럼 가까운 표현이나 감정·분위기 간 경계가 항상 안정적으로 분리된다는 보장도 없습니다.

지금은 고정된 단어 안에서 가까운 후보를 얻고 어울리는 표현을 선택하는 용도로 사용할 수 있습니다. 모델 변경이나 추가 학습의 필요성과 예상 개선량을 현재 자료만으로 수치화하지 않습니다.

## 공개 범위와 원문 보존

이번 공개본에는 공개 데이터 기반 분석·비교·평가 보고서 16개와 지표 안내를 포함했습니다. 개인 노트·개인 플레이리스트·곡별 개인 피드백·음원·모델 가중치·원시 평가 자료·전체 실험 도구는 포함하지 않았습니다. 따라서 보고서만으로 모든 과거 수치를 처음부터 재현할 수 있는 묶음은 아닙니다.

보고서의 결과·결론은 유지하고 과거 버전 안내를 추가했습니다. 공개하지 않은 상대 문서 링크는 로컬 보관 문서라는 텍스트로 바꿨습니다. 원문·공개본의 SHA256과 변환 내역은 [공개 기록](publication-manifest.json)에 남겼습니다. 원본 로컬 문서를 수정하거나 새 점수를 만들어 채우지 않았습니다.
