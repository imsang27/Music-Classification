# 감정·분위기 오류 유형과 개선 방향

> 과거 실험 기록 · 공개본 2026-10-29. 본문의 모델·라벨·기본값·다음 단계는 작성 당시의 상태입니다. 현재 0.6.0 familiar 구성의 정확도를 뜻하지 않습니다. [현재 구성과 해석 범위](../README.md)를 먼저 확인하세요. 본문의 로컬 원시 자료·실험 도구는 이 공개본에 포함하지 않습니다.


2026-10-25

## 결론

세 항목의 성능 하락은 고정된 경계값이 다른 표본의 점수 분포에 잘 맞지 않은 데서 발생했다. 점수 순위가 함께 무너진 결과는 아니다. 행복은 순위 성능이 거의 같고, 슬픔과 편안함은 보류 자료에서 오히려 높았다. 행복·슬픔은 원래 점수의 긍정·부정 겹침도 있어 경계 조정만으로 모든 오류를 해결할 수 없다.

작은 보정 표본에 대한 과도한 적합과 표본 구성 차이는 가능한 설명이다. 다만 이 두 집합만으로 어떤 음악적 특성이나 데이터 수집 요인이 원인인지 확정할 수는 없다.

## 이번에 한 작업

보정 48곡과 보류 48곡의 고정된 점수·공개 합의 라벨을 다시 계산했다. 곡별로 기존 정답 유지, 오류 개선, 새 오류, 기존 오류 유지로 나누고 기존 지표 및 혼동 수와 일치하는지 확인했다. 새 모델 추론·경계 탐색·가중치 학습·기본 API 변경은 하지 않았다. 직접 청취한 분석이 아니므로 곡의 실제 음악적 원인을 들었다고 주장하지 않는다.

## 경계 변경으로 바뀐 곡

개선은 기존 오답→보정 정답, 새 오류는 기존 정답→보정 오답을 의미한다. 괄호 안의 값은 각 집합 내 보정 전후 균형 정확도 차이다. 보정 자료의 직접 적합 결과는 낙관적이다.

| 항목 | 보정 자료 개선 / 새 오류 | 보류 자료 개선 / 새 오류 | 보류 자료의 직접 원인 |
|---|---:|---:|---|
| 행복 | 6 / 4 (+24.6%p) | 2 / 7 (-9.0%p) | 누락 2곡 해소 대신 새 오탐 7곡 |
| 슬픔 | 3 / 3 (+11.6%p) | 1 / 4 (-2.1%p) | 누락 1곡 해소 대신 새 오탐 4곡 |
| 편안함 | 5 / 0 (+10.4%p) | 2 / 4 (-9.5%p) | 오탐 2곡 해소 대신 새 누락 4곡 |
| 공격성 | 2 / 0 (+12.5%p) | 3 / 1 (+13.3%p) | 누락 3곡 해소, 새 오탐 1곡 |

## 항목별 진단

### 행복

경계 0.5를 0.162274로 낮춰 점수 [0.162274, 0.5) 구간을 새로 긍정으로 판단했다. 이 구간은 보정 자료에서 긍정 6곡·부정 4곡이었지만 보류 자료에서는 긍정 2곡·부정 7곡이었다. 같은 규칙이 새 표본에서 오탐을 더 많이 늘렸다. 긍정·부정 순위의 겹침도 남아 있어, 더 낮은 경계만으로 해결할 수 없다.

### 슬픔

경계 0.5를 0.240458로 낮춘 구간에는 보정 자료에서 긍정 3곡·부정 3곡, 보류 자료에서 긍정 1곡·부정 4곡이 있었다. 보류 자료에서는 긍정 9곡 중 원래도 7곡을 맞혔으므로 낮은 경계로 추가 검출할 이득이 작았다. 부정 26곡 중 오탐은 8곡에서 12곡으로 늘었다.

### 편안함

보정 자료의 긍정 11곡은 최소 점수가 0.916260으로 모두 높았다. 그 자료에서는 경계를 0.907822까지 올려도 긍정을 놓치지 않고 오탐 5곡을 줄였다. 하지만 보류 자료에는 점수 0.824930~0.896898인 긍정 4곡이 있었고, 새 경계가 이들을 모두 놓쳤다. 이는 단순히 0.9에 가까운 높은 점수를 요구하는 것이 위험할 수 있음을 보여준다. 점수 자체를 정답 확률로 해석해서도 안 된다.

### 공격성 — 비교 항목

보류 자료에서는 누락이 3곡 줄고 새 오탐은 1곡이었다. 다른 세 항목과 달리 개선 방향이 유지됐지만 긍정 10곡의 작은 표본이며 차이의 불확실성 구간도 0을 포함한다. 공격성의 개선을 다른 항목에도 동일 보정 방식을 적용할 근거로 사용하지 않는다.

## 점수 순위와 경계를 구분한 결과

ROC-AUC는 긍정 곡이 부정 곡보다 높은 점수를 받는 정도를 나타낸다. 0.5는 무작위 순위 수준이다. 경계값만 바꾸면 같은 점수의 AUC는 달라지지 않는다. 서로 다른 두 표본의 AUC 차이를 모델 자체의 개선으로 해석하면 안 된다.

| 항목 | 보정 자료 AUC | 보류 자료 AUC | 보류 긍정·부정 점수 역전 쌍 / 전체 쌍 |
|---|---:|---:|---:|
| 행복 | 0.754 | 0.747 | 69 / 273 |
| 슬픔 | 0.732 | 0.838 | 38 / 234 |
| 편안함 | 0.966 | 0.973 | 6 / 221 |
| 공격성 | 0.987 | 0.970 | 9 / 300 |

행복은 AUC 약 0.75로 긍정·부정의 겹침이 뚜렷하다. 슬픔은 보류 자료의 순위는 더 나았지만 낮춘 경계가 오탐을 늘렸다. 편안함은 AUC 약 0.97을 유지하므로 이번 하락을 특징 추출 모델 전체의 실패로 볼 근거는 약하다.

## 확인된 사실과 아직 확인하지 못한 원인

- 확인: 낮춘 경계의 점수 구간에 보류 자료의 부정 곡이 더 많이 들어왔다. 높인 편안함 경계 아래에 보류 자료의 긍정 곡 4개가 있었다.
- 확인: 보정 자료의 긍정은 항목별 8~11곡이다. 편안함 보정에 중간 점수 긍정 사례가 없었던 사실이 확인된다.
- 가능성: 작은 표본의 최적 경계에 과도하게 맞춘 영향과 라벨별 확보·다운로드 가능성에 따른 표본 구성 차이. 인과관계 확정은 아니다.
- 미확인: 어떤 악기·템포·보컬·구간 변화·음질이 개별 오류를 유발했는지. 현재 점수와 장르 태그만으로 음악적 원인을 단정하지 않는다.
- 미확인: J-pop에 같은 현상이 얼마나 나타나는지. 현재 자료를 J-pop 성능 근거로 바꾸지 않는다.

## 개선 방향과 우선순위

1. 보정값 일괄 적용을 보류한다. 현재 기본 API와 고정 경계를 유지한다. 기존 0.5는 비교 기준이며 검증된 정답 확률 경계라는 뜻은 아니다.
2. 추가 추론이나 모델 교체 전에 보정 방법부터 검증한다. 기존 0.5를 유지하는 후보와 더 보수적으로 움직이는 경계 후보를 개발 자료의 아티스트 단위 중첩 교차검증 안에서 비교한다. 새 후보 선택 규칙은 결과를 보기 전에 고정한다.
3. 행복·슬픔은 점수 겹침도 있으므로 보정 후보가 반복 검증에서 도움이 없을 때 음악 표현 모델·전문 분류기 비교로 확장한다. 편안함은 기존 순위를 활용하는 보수적 경계 방식부터 검토한다. 모델 변경을 미리 결정하지 않는다.
4. 새 최종 검증 자료는 기준을 고정한 뒤 별도로 확보한다. 이번 48곡은 오류를 분석한 진단 자료가 됐으므로 개선한 모델의 독립 최종 평가에 다시 사용하지 않는다.
5. J-pop 중심 판단을 위해 J-pop 공개 참조·사용 가능한 오디오 확보 경로를 별도로 조사한다. 공개 합의나 신뢰할 만한 참조가 있는 범위부터 검증하며, 사용자가 장르 전문가처럼 직접 정답을 작성하도록 요구하지 않는다. 참조가 없으면 정확도를 산출했다고 주장하지 않는다.

이 단계에서는 새 경계·새 모델을 선택하지 않았다. 위 개선안의 효과는 아직 시험하지 않았으며, 향후 후보 채택 시 현재 보류 결과는 선택 이후 성능의 독립 근거가 될 수 없다.

## 검증과 보존

오류 전이·균형 정확도 기여도·AUC를 기존 고정 지표와 대조했고 모든 값이 일치했다. 원래 보정·평가 JSON 해시는 분석 전후 동일하다. 오류 분석 테스트 4개로 경계를 낮추거나 높였을 때의 전이, 누락 라벨 제외, 동점 및 잘못된 입력 처리를 확인했다.

- scripts/analyze_mood_errors.py: 새 추론이나 경계 선택 없이 고정 결과 분석.
- music_classification/error_analysis.py: 점수 요약·곡별 전이·정확도 차이 분해.
- data/evaluation/mood_error_analysis_v1/analysis.json: 전체 곡별 진단과 원본 증거 해시.

현재 사용자가 추가로 할 일은 없다. 다음 단계로 제안한 보수적 보정 후보의 검증 절차 설계 및 구현은 별도 승인 후 진행한다.
