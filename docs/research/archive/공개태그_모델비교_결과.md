## 결론

사용자의 장르 판정 없이 공식 MTG-Jamendo 태그를 기준으로 실제 모델 3종을 비교했다. 36개 후보 중 서버에서 받아 공식 체크섬이 일치한 10개만 평가했다. 표본 부족·가용성 편향·불완전한 업로더 태그 때문에 최종 모델을 확정하거나 J-pop 정확도로 일반화할 수 없다.

## 첫 후보의 등록 태그 포함 여부

| 평가 범위 | 기존 Wav2Vec2 | CLAP | 지도학습 EffNet+MTG 헤드 |
|---|---:|---:|---:|
| 공통 10장르, 해당 태그가 있는 8곡 | 3/8 | 5/8 | 5/8 |
| 원래 87장르, 10곡 | 해당 없음 | 0/10 | 6/10 |
| 원래 56분위기·주제, 해당 태그가 있는 4곡 | 해당 없음 | 1/4 | 1/4 |

이 표의 지표는 hit@1이다. 가장 높은 점수의 라벨이 관측된 태그 목록에 있으면 포함으로 센다. 사람이 실제로 느낀 감정이나 음악학적 정답률을 뜻하지 않는다. 한 곡에 여러 태그가 가능하며, 등록되지 않았다고 반드시 틀린 라벨은 아니다. 분위기·주제 56개는 감정·분위기가 분리된 자체 8+8 라벨과 다른 체계다.

## 순위 지표

다음 mAP는 양성·음성 예제가 모두 있는 라벨에 대해 sklearn average_precision_score를 평균한 값이다. 통상적인 PR-AUC의 사다리꼴 면적과 같지 않고 모델 공식 카드의 PR-AUC와 직접 비교할 수 없다. 태그 누락을 음성으로 처리한 한계가 있다.

| 평가 범위 | CLAP mAP | EffNet mAP | 기존 Wav2Vec2 mAP |
|---|---:|---:|---:|
| 공통 10장르, 유효 라벨 7개 | 0.665 | 0.650 | 0.765 |
| 원래 87장르, 유효 라벨 29개 | 0.457 | 0.566 | 해당 없음 |
| 원래 56분위기·주제, 유효 라벨 7개 | 0.476 | 0.738 | 해당 없음 |

모든 곡에 빈도 1위 태그만 내는 비교 기준의 hit@1은 각 평가 묶음에서 0.5였다. 따라서 일부 결과는 이 단순 기준보다도 낮다. 지표에 따라 모델 순위가 바뀌므로 하나의 수치만 보고 우수 모델로 확정하지 않는다.

- 원래 파일과 태그의 대응은 확인했지만, 업로더 태그를 전문가 전수 검증 정답으로 간주하지 않는다.

## 추론 조건

CLAP/Wav2Vec2는 곡 전체를 연속 10초 구간으로 나눠 처리하고, 각각 코사인 유사도와 softmax 점수를 평균했다. 1초 미만 끝부분·디지털 무음 구간은 제외했다. CLAP은 고정 문구로 87장르와 56분위기·주제를 평가했고, 10장르 비교에서는 같은 점수 중 공통 라벨만 사용했다. 이 파일럿 결과를 본 후 문구를 튜닝하지 않았다.

EffNet은 공식 ONNX 임베딩 모델과 MTG-Jamendo 분류 헤드를 CPU로 실행했다. 전체 오디오를 16kHz로 바꾸고 512점 대칭 Hann·hop256·96개 Slaney 멜 필터·로그 압축을 적용한 뒤 128프레임 패치(hop62)의 헤드 sigmoid를 평균했다. 프레임 전처리는 공식 Essentia WebAssembly 구현의 독립 출력과 비교해 최대 절대 오차 약 5.75e-6을 확인했고 회귀 테스트로 보관했다. 전체 TensorFlow 추론과의 비트 단위 동일성을 확인한 것은 아니다.

Wav2Vec2의 과거 weight_norm 키를 현재 키로 명시적으로 매핑하고 저장 체크포인트를 strict 로딩했다. 모델을 새로 학습하거나 임의 가중치로 대체하지 않았다.

모델별 시간 해상도와 출력 점수 척도는 다르므로 원시 점수의 크기나 실행 시간만으로 품질을 비교하지 않는다. 모델·음원·구간·원시 점수는 JSON에 보관했다.

## 남은 한계

- 공식 분할의 독립성과, 이미 배포된 모델 학습 자료의 독립성은 다르다. EffNet 헤드의 정확한 학습 분할과 CLAP 사전학습 자료에 대한 중복은 확정하지 못했다.
- mood/theme 태그가 없는 6곡은 분위기 성능 분모에서 제외했다. 빈 태그를 무감정·분위기 없음의 정답으로 간주하지 않았다.
- 각 라벨의 표본이 너무 적어 신뢰구간·희소 장르 성능·최종 수용 기준을 확정하지 않았다.
- 자체 감정·분위기 표현 및 J-pop 성능은 여전히 미검증이다.
- 이번에는 모델 선택에 필요한 개발 파일럿을 수행했으며 최종 평가를 완료하지 않았다.

## 다음 작업

장르 후보는 지도학습 모델을 포함해 표본을 확대하고, 분위기·감정은 더 많은 주석 자료로 별도 검증해야 한다. 현재의 낮은 분위기 성능을 사용자 수동 태깅으로 덮지 않는다. 실제 출력을 바꾸는 기본 모델 교체는 하지 않았다.
