# Emotify+ 사람 감정 강도와 모델 점수 비교

> 과거 실험 기록 · 공개본 2026-10-29. 본문의 모델·라벨·기본값·다음 단계는 작성 당시의 상태입니다. 현재 0.6.0 familiar 구성의 정확도를 뜻하지 않습니다. [현재 구성과 해석 범위](../README.md)를 먼저 확인하세요. 본문의 로컬 원시 자료·실험 도구는 이 공개본에 포함하지 않습니다.


2026-10-25

현재 모델 점수가 사람이 선택한 감정의 강도를 안정적으로 따라간다는 근거를 얻지 못했다. Music2Emo happy에서 약한 양의 순위 관련성이 나타났지만, 계산한 일곱 비교의 탐색적 95% 구간은 모두 0을 포함했다. 기존 장르·Music2Emo API를 유지하며 별도 감정 축을 검증 완료로 바꾸지 않는다.

## 실제 비교 결과

기준은 Emotify+에서 같은 감정을 명시적으로 선택한 서로 다른 평가자 최소 3명의 평균 점수다. 감정별 표본이 다르며 같은 음원이 여러 항목에 들어갈 수 있다. happy와 joyful를 합치지 않았다.

| 사람 평가 항목 | 곡 수 | CLAP 순위 상관 ρ [탐색적 95% 구간] | Music2Emo 순위 상관 ρ [탐색적 95% 구간] |
|---|---:|---|---|
| happy | 29 | −0.217 [−0.559, 0.181] | 0.308 [−0.054, 0.623] |
| joyful | 20 | −0.110 [−0.562, 0.353] | 0.279 [−0.312, 0.708] |
| sad | 21 | 0.158 [−0.375, 0.591] | 0.130 [−0.427, 0.595] |
| anxious | 25 | 0.060 [−0.283, 0.392] | 해당 출력 없음 |

ρ는 Spearman 순위 상관이다. +1에 가까울수록 사람이 더 강하게 평가한 곡에 모델도 더 높은 점수를 준다. 0에 가까울수록 단조 관계가 약하고, 음수는 반대 방향이다. **정확도 백분율이 아니다.**

Music2Emo의 happy 추정치가 CLAP보다 높게 나타났지만, 라벨 대응의 차이와 작은 표본·넓은 구간을 고려해야 한다. 이번 결과로 모델의 일반적 우월성이나 효과가 없다는 결론을 확정하지 않는다. 음수 결과를 보고 점수 부호를 뒤집거나 문구·라벨·임계값을 바꾸지 않았다.

## 모델과 사람 라벨의 대응

| 사람 라벨 | CLAP 점수 | Music2Emo 점수 |
|---|---|---|
| happy | 기존 joy 문구의 관련도 | 원래 happy sigmoid |
| joyful | 기존 joy 문구의 관련도 | happy sigmoid를 관련 라벨의 보조 비교로만 사용 |
| sad | 기존 sadness 문구의 관련도 | 원래 sad sigmoid |
| anxious | 기존 anxiety 문구의 관련도 | 미지원 |

CLAP은 happy와 joyful에 같은 joy 점수를 사용하므로 둘을 구별하는 모델로 검증한 것은 아니다. Music2Emo의 happy→joyful도 직접 라벨 일치 검증이 아니다. Music2Emo의 VA나 다른 태그에서 불안 점수를 만들어내지 않았다.

## 분석 구간·실행 방식

- 주석 준비 단계에서 고정한 파일 목록과 최소 평가자 수를 그대로 사용했다. 원래 배포 음원 전체를 분석했고 전곡·유튜브 영상으로 대체하지 않았다.
- CLAP은 고유 음원 54개, Music2Emo는 42개에서 추론했다. 일곱 감정·모델 비교에 필요한 총 96회 파일·모델 추론이 성공했다.
- CLAP은 기존 `laion/larger_clap_music` revision `a0b4534a14f58e20944452dff00a22a06ce629d1`와 기존 감정 문구 8개를 유지했다. 이번 연구 실행에서는 전체 음원을 빠짐없이 덮도록 **10초 이하의 균등 구간**으로 나누고 cosine similarity를 동일 가중 평균했다. 이전 CLAP 어댑터의 1초 미만 꼬리 제외 방식과 구분되는 연구용 구간 정책이며 기본 API는 변경하지 않았다.
- Music2Emo는 이전에 검증한 mode 수정본, 원래 가중치·MERT·키·코드 처리를 유지했다. 같은 원본 파일 전체에 30초 MERT 구간 평균을 사용하고 1초 미만 꼬리는 앞 구간에 합쳤다. 전용 실행 폴더에서 모델을 한 번 로드해 순서대로 추론했다.
- 별도 API로 `classical/24.mp3`를 다시 실행했을 때 Music2Emo의 56개 점수는 배치 결과와 전부 같았다. 최대 절대 차이 0.0.
- 모델마다 처리하는 구간 길이·특징과 점수 의미는 다르다. 원본 음원 범위는 같지만 서로의 점수를 직접 합산하거나 같은 단위의 강도로 간주하지 않는다.

## 불확실성과 해석 범위

순위 상관의 구간은 파일의 사람 평균값·모델 점수 쌍을 함께 재추출하는 2,000회 부트스트랩으로 계산했다. seed는 20261025이며 매 재추출에서 동점을 포함한 순위를 다시 계산했다. 상수 표본은 상관을 0으로 만들지 않고 정의 불가로 제외한다. 이번 일곱 항목에서는 각각 2,000개 재추출 값이 모두 유효했다.

이 구간은 관측된 평균 평가값에 조건부인 탐색적 구간이다. 같은 평가자가 여러 곡을 평가한 의존성, 반복된 곡, 평가자 평균 자체의 오차와 여러 비교에 대한 보정은 포함하지 않았다. 따라서 엄밀한 유의성 검정이나 출시 기준으로 사용하지 않는다.

이 자료는 감정을 선택한 사람의 강도 평가다. 선택하지 않은 감정을 부정 정답·0점으로 보충하지 않았다. 모델 점수는 감정 강도로 보정되어 있지 않으며, 상관을 계산했다고 보정된 강도 예측기가 되는 것도 아니다. 감정 유무의 정확도·F1·균형정확도는 이번에 계산하지 않았다.

이전 MTG happy/sad 비교는 감정 유무에 대한 사람 판정을 사용했다. 이번 비교는 해당 감정을 선택한 사람들 사이의 강도 순위를 사용하므로 서로 다른 평가다. 이번 낮은 상관이 이전 감정 유무 실험을 무효화하거나, 반대로 이전 결과가 이번 강도 예측을 입증하지는 않는다.

J-pop, 자체 감정 8종 전체, 모델 사전학습 자료와의 비중복은 검증되지 않았다. 모델 학습·문구 조정·임계값 조정은 하지 않았다.

## 검증과 산출물

- 전체 자동 테스트 **103개 통과**. 추가한 7개는 순위와 점수 단위 구분, 역순위, 동점, 상수값의 정의 불가 처리, 재현 가능한 부트스트랩, 잘못된 쌍 거부와 유효 재추출 수를 확인했다.
- 별도 감사에서 체크포인트·런타임·설정·평가 자료·음원 해시를 검증하고 일곱 상관 및 구간을 재계산했다.
- CLAP의 전체 음원 구간 연결·끝점·누락 없음과 Music2Emo의 원래 파일 범위를 확인했다.
- 결과를 동결했으며 재실행은 `ALREADY_FROZEN`으로 종료했다.
- `data/evaluation/emotify_intensity_v1/`: 고정 계획, 모델별 곡 점수, 통계 결과와 동결 해시.
- `scripts/run_emotify_intensity.py`, `scripts/intensity_statistics.py`, `scripts/audit_emotify_intensity.py`: 실행·통계·감사 도구.

현재 사용자가 직접 할 일은 없다. 후속 후보는 대체 음악·텍스트 모델을 같은 문구·음원·평가 기준으로 비교하는 것이다. 예를 들어 MuQ-MuLan은 공식적으로 음악·텍스트 관련도를 제공하는 후보지만, 이번에는 설치하거나 측정하지 않았으며 더 나은 결과를 보장하지 않는다. [공식 모델 설명](https://huggingface.co/OpenMuQ/MuQ-MuLan-large)
