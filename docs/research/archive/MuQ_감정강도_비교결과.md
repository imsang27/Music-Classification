# MuQ-MuLan 감정 강도 비교 결과

> 과거 실험 기록 · 공개본 2026-10-29. 본문의 모델·라벨·기본값·다음 단계는 작성 당시의 상태입니다. 현재 0.6.0 familiar 구성의 정확도를 뜻하지 않습니다. [현재 구성과 해석 범위](../README.md)를 먼저 확인하세요. 본문의 로컬 원시 자료·실험 도구는 이 공개본에 포함하지 않습니다.


2026-10-25

MuQ-MuLan을 별도 환경에 준비하고 같은 54개 음원·기존 감정 문구·사람 강도 평가 기준으로 비교했다. 기쁨 계열에서 개선의 징후는 있었지만, 기존 모델과의 차이에 대한 탐색적 구간은 일곱 비교 모두 0을 포함했다. **기존 모델보다 확실히 낫다고 판단할 근거는 부족하다.** 기존 API와 기본 모델은 유지한다.

## 실제 결과

표의 수치는 Spearman 순위 상관 ρ다. 사람이 더 강하게 평가한 곡에 모델도 더 높은 점수를 주는 정도이며 정확도 백분율이 아니다. +1에 가까울수록 잘 일치하고, 0에 가까우면 단조 관계가 약하다.

| 사람 평가 | 곡 수 | 기존 CLAP | Music2Emo | MuQ-MuLan | MuQ 탐색적 95% 구간 |
|---|---:|---:|---:|---:|---|
| happy | 29 | −0.217 | 0.308 | **0.369** | [0.018, 0.646] |
| joyful | 20 | −0.110 | 0.279 | **0.437** | [−0.025, 0.746] |
| sad | 21 | 0.158 | 0.130 | 0.119 | [−0.342, 0.558] |
| anxious | 25 | 0.060 | 미지원 | 0.167 | [−0.228, 0.520] |

happy에서는 관측된 평균 강도와 양의 관련성이 나타났다. 하지만 작은 선택 표본에서 계산한 구간이며, 다중 비교·반복된 곡·공유 평가자를 보정한 확증 결과는 아니다. joyful는 추정치가 더 높지만 구간이 넓고 0을 포함한다. 슬픔·불안에서는 뚜렷한 개선을 확인하지 못했다.

모델 간 개선 여부는 동일한 곡을 함께 재추출하여 상관 차이도 계산했다. 아래 차이는 `MuQ − 기존 모델`이며 정확도 향상률이 아니다.

| 사람 평가 | CLAP 대비 ρ 차이 [탐색적 95% 구간] | Music2Emo 대비 ρ 차이 [탐색적 95% 구간] |
|---|---|---|
| happy | 0.585 [−0.023, 1.101] | 0.061 [−0.389, 0.503] |
| joyful | 0.547 [−0.247, 1.194] | 0.157 [−0.275, 0.608] |
| sad | −0.039 [−0.580, 0.610] | −0.011 [−0.444, 0.404] |
| anxious | 0.106 [−0.297, 0.488] | 해당 비교 없음 |

기쁨 계열의 점 추정치는 좋아졌지만 모델 간 차이를 확정할 만큼 불확실성이 줄어들지는 않았다. 결과를 보고 점수 부호·감정 문구·임계값을 조정하거나 모델을 자동 교체하지 않았다.

## 동일하게 유지한 기준

- 기존 Emotify+ 자료와 최소 3명 독립 선택 평가 기준을 유지했다. 빠진 감정을 부정 정답·0점으로 채우지 않았다.
- CLAP에 사용한 감정 문구 8개를 그대로 사용했다. happy와 joyful는 둘 다 joy 문구 점수로 비교하되 사람 평가값은 각각 유지했다. 두 감정을 구별하는 모델로 검증한 것은 아니다.
- sad는 sadness, anxious는 anxiety 문구 점수와 비교했다. 기존 Music2Emo의 anxious 미지원 상태도 그대로 보존했다.
- 같은 원본 파일 전체를 24kHz 모노 FP32로 읽었다. CLAP 비교와 같은 기준으로 전체를 덮는 10초 이하 균등 구간을 만들고 원래 MuQ-MuLan의 관련도 점수를 평균했다.
- MuQ의 원래 추론 래퍼는 짧은 구간의 앞부분을 반복해 10초 입력을 채운다. 이를 유지했으며 원본 구간을 버리거나 별도 곡으로 바꾸지 않았다. 모델별 입력 주파수·특징 추출과 패딩은 다르다.
- Spearman과 2,000회 파일 쌍 부트스트랩, seed20261025를 유지했다. 상관 차이는 같은 재추출에서 기존 모델과 후보 모델을 함께 평가했다.

이 자료의 정답은 **해당 감정을 선택한 사람들의 평균 강도**다. 선택하지 않은 사람·곡에 대한 감정 유무는 알 수 없다. 이번 결과는 감정 유무의 정확도·F1·균형정확도, 보정된 감정 강도 출력, J-pop 정확도 또는 자체 감정 8종 전체의 검증이 아니다.

구간은 관측된 평균값에 조건부인 탐색적 구간이다. 공유 평가자·반복 곡·평가자 평균의 오차·다중 비교를 보정하지 않았다. 앞선 결과를 본 뒤 후보 모델을 추가했으므로 새로운 독립 최종 시험으로 간주하지 않는다. 모델 사전학습 자료와 음원 비중복도 인증하지 못했다.

- 전체 가중치: 2,653,954,401바이트. 게시자 LFS SHA256 `d42ae3f7cb9b66759ee0089ddc70e2f28b130c2d8ba621457358272d32dd0444`와 일치했다.

원본 코드와 모델 파일을 고정하고, 로컬 구성·토크나이저만 사용하도록 런타임 변경을 기록했다. 공식 모델은 음악·텍스트 관련도 모델이며 결과가 감정 확률이라는 뜻은 아니다. 가중치 라이선스는 CC-BY-NC-4.0으로, 다른 곳에 배포·재사용할 때 함께 검토해야 한다. [공식 모델 설명](https://huggingface.co/OpenMuQ/MuQ-MuLan-large), [공식 코드](https://github.com/tencent-ailab/MuQ)

## 호환 처리와 검증

첫 계획 v1은 추가 state 검사에서 구형 `weight_g/weight_v`와 현재 PyTorch의 `parametrizations.weight.original0/original1` 키 이름 차이를 발견해 실제 평가 예측 전에 중단했다. 실패 당시 코드·계획·진단을 보존했다.

v2에서는 해당 위치 합성곱의 두 키만 명시적으로 대응시켰다. 알 수 없는 키·누락·중복 이름은 계속 오류로 처리한다. 모든 텐서의 값이 정확히 같은지 확인한 후 음원 54개에서 추론했다. 가중치나 감정 문구를 학습·조정한 변경은 아니다.

- 전체 자동 테스트 **112개 통과**. 이번 추가 9개는 쌍별 상관 차이·재현성·동점·정의 불가 처리와 구형 키 대응·값 보존·모호한 키 거부를 검증했다.
- 실제 54개 음원에서 감정 문구 점수 8개씩 생성했다. 누락·비유한 점수나 실패 파일을 임의 결과로 채우지 않았다.
- 별도 감사에서 모델·코드·설정·입력 해시, 전체 구간 연결과 누락 없음, 네 후보 상관과 일곱 차이·구간을 재계산했다.
- 결과를 동결했으며 재실행은 `ALREADY_FROZEN`으로 종료했다.

산출물은 `data/evaluation/muq_emotify_intensity_v2/`의 계획·곡별 점수·통계·동결 해시와 `scripts/run_muq_emotify.py`, `scripts/audit_muq_emotify.py`다. 원본 모델과 별도 환경은 `work/muq-experiment/`, `work/muq-env/`에 있다.

현재 사용자가 직접 라벨링하거나 설정할 일은 없다. MuQ는 기쁨 관련 실험 후보로 남겨두되, 이번 결과만으로 별도 감정 축을 검증 완료 상태로 바꾸지 않는다. 다음 작업 후보는 검증 한계를 명시한 선택형 감정 후보 어댑터로 연결하는 것이다. 실제 연결은 이번 비교 단계에서 하지 않았다.
