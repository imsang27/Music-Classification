음악 선택

WAV · MP3 · FLAC · OGG · M4A · AAC
최대 20개 / 파일당 100MiB / 합계 500MiB

    20분 이하의 공개 영상 한 곡을 지원합니다. 재생목록 전체나 로그인이 필요한 영상은 사용할 수 없습니다.

    준비한 오디오는 분류 후 삭제됩니다. 제목과 채널 정보는 분류 근거로 사용하지 않습니다.

    최대 10개를 순서대로 처리합니다. 실패한 링크도 결과에 남고, 다음 링크는 계속 처리합니다. 재생목록 전체 링크는 지원하지 않습니다.

    감정 · 1~3개
    분위기 · 1~3개

    직접 선택한 값을 저장합니다. 모델 분석이나 학습은 수행하지 않고 노트에도 자동 적용하지 않습니다.

    원본 음원과 Obsidian 노트는 수정하지 않습니다.
    가사 의미를 해석하지 않고 소리의 인상을 분석합니다.

    음악을 골라주세요

    분류가 끝나면 감정과 분위기를 각각 세 가지 후보로 보여드릴게요.

    업로드 폴더 관리

    새 분석용 오디오는 완료 후 삭제합니다. 이곳에서는 기존 업로드 폴더에 보관된 파일을 확인하고 정리할 수 있습니다.

    파일 목록을 확인합니다.

      정리한 파일은 복구 가능한 별도 보관함으로 이동합니다. 원본 노트와 분석 결과 파일은 건드리지 않습니다.

      기존 페이지의 기타 기능

      기존 버튼의 구현 상태를 구분해 안내합니다.

      통합 분류 미구현

      여러 모델의 결과를 결합할 기준과 검증이 아직 없습니다. AI 탭의 모델 선택은 결과를 합치는 기능이 아닙니다.

      가사 분석 현재 범위 제외

      이 프로젝트는 가사 의미를 제외하고 소리의 인상을 분류합니다.

      1순위는 대표값이며, 나머지는 대안 후보입니다. 세 후보가 모두 확정 태그이거나 점수가 정답 확률을 뜻하지는 않습니다.

      보관 파일을 정리할까요?

      현재 목록의 음원만 복구 가능한 보관함으로 이동합니다. 진행 중인 분석과 노트는 변경하지 않습니다.
